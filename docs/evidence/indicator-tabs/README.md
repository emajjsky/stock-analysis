# 指标标签与量图验证

本次验证覆盖个股详情页的 K 线与分时图：

- 主图指标改为可直接点击的标签按钮：均线 MA、布林带 BOLL、指数均线 EXPMA、多空均线 BBI、抛物线 SAR。
- 副图指标改为可直接点击的标签按钮，K 线支持 MACD、KDJ、RSI、OBV、W&R、MTM、VR、ARBR、DMI、BIAS、DMA、ASI、TRIX、DPO。
- 量图补充成交量、成交额切换，以及 MA5 / MA10 开关。
- 分时成交额只使用同源累计成交额差分；历史数据没有成交额时显示来源未提供，不用价格乘成交量伪造。
- 验证了 1920、1366、1093、390 宽度下无横向溢出，轮询刷新不会重置用户选择。

证据文件：

- `01-intraday-tabs.png`：分时量图与副图标签。
- `02-kline-tabs.png`：日 K 主图、量图、副图标签。
- `03-mobile-tabs.png`：移动宽度下的标签布局。
- `results.json`：脚本化验证结果。

前端单元测试为 11 个文件、45 项通过；生产构建通过。
