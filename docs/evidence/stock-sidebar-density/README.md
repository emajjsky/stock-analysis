# 个股右侧五档与筹码密度优化

验收日期：2026-11-06。正式本地服务为 `http://127.0.0.1:8765`，测试期间未重启服务。

## 页面调整

- 买卖五档使用约 28px 固定档位行高，避免五档被拉开填满侧栏；空出的区域补入五档委比、委买量、委卖量、五档委差、买卖价差和最近五笔真实成交。
- 顶部统一显示基础行情；右栏“成交与估值”仅展示顶部没有的内外盘、市净率、静态/TTM市盈率、流通市值、总/流通股本共八项。逐笔页仅保留内外盘摘要。缺失值显示“—”，逐笔接口失败时保留五档并显示错误。
- 筹码摘要改为紧凑双列，价格轴围绕模型估算的90%成本区间，按2px逐档重采样绘制140档并铺满300px绘图区；极端历史价不再拉伸主分布，收盘价线与当前显示区间共用价格坐标。柱长是原模型筹码量的线性插值，仅用于显示密度，不改变汇总指标。保留获利/套牢比例、成本区间、集中度及成交与估值补充参数。默认除权/不复权；缺日线和缺流通股本分别说明。
- 图表游标用预建日期索引定位K线；筹码模型缓存已算快照，新增或更新末根K线时只增量重算，并按证券及复权周期隔离缓存。
- 筹码仍标注为日线量价与流通股本估算；没有真实数据的主力持仓成本继续显示“未接入数据”。
- 个股默认除权/不复权；在该口径下执行手动行情刷新时会同步未复权日线。筹码空态分别提示缺少日线或有效流通股本。
- 鼠标定位按日期索引查K线；历史价格范围不变时筹码分布复用已计算前缀，只增量重算新增或修订部分，缓存按证券/周期/复权口径隔离。零价或无效OHLC记录不再令整段价格轴失效，首根有效K线没有成交量时也会初始化估算分布。
