# 2026-11-06 板块看盘验收

用户提供同花顺热点、轮动、分析、资金、新概念及期股页面作为功能参考，纠正此前市场页的证券目录空态。规格见 [板块看盘增量](../../MARKET-BOARDS.md)。

本轮实现：行业/概念板块榜、表头排序和搜索、成分股与板块/个股两图联动、分时/不复权日K、成交额面积热力图、资金净额排行与20日序列、真实源交易日Top10存档和上榜次数。目录保留次级入口，名称打开原有个股详情，加入自选复用原有逻辑。刷新按钮实际POST重试当前板块和股票，不改变自动开关。

正式服务 `http://127.0.0.1:8765/#/market`，仅一个端口监听，检查时PID101196；前端构建由同一服务静态托管，数据库沿用 `.local/workstation.db`。

## 真实数据

[API实测](live-api.json)：行业496、概念531；BK1518种子板块分时241点、日线160根、资金20日。来源成分10只，本项目沪深普通A股范围支持8只，页面明确显示8/10，不把范围外证券生成假身份。报价采用源时间，抓取时间单独记录；资金为东方财富估算，不能视作真实机构增仓。

轮动当前只积累1个源交易日，后续成功更新按源交易日累计，最多展示10日。未提供同花顺主力持仓增仓、新概念创建时间或期股主题映射，不使用净流入或抓取日期冒充。行业采用东方财富分类且包含细分，与同花顺分类并不一一对应。
