# 概念重复、ETF匹配与债股联动核验

日期：2026-11-07

## 结论

- 东方财富概念行情榜当前返回531个板块；同花顺“最新概念”接口返回10条事件，其中7条能与概念榜完全同名映射。它们的数据语义不同，但当前页面映射后展示同一概念行情详情，事件字段没有形成独立工作流，因此导航移除“最新概念”，改为“债股联动”。最新概念接口仍保留供后续接入事件字段。
- ETF行情返回1659只场内基金；季度披露前十大持仓样本当前只有21只主题ETF，不代表全部ETF组合或实时持仓。此前任意一只重合就列为候选，会把跨行业的偶然持仓误当成概念ETF。
- 现在名称/人工主题匹配继续展示；披露持仓交集必须至少3只，且这些成分在该ETF最新一期披露前十大中的净值权重合计不少于20%。这是一条保守的页面候选规则，不是交易所或基金行业标准。持仓没有返回时显示“正在读取ETF披露持仓…”，请求失败显示不可用，与无可靠匹配分开。
- 实际样本中“AI应用”有296只成分，可命中名称/产业主题ETF；“2026三季报预增”有109只成分，旧逻辑会因若干ETF披露前十大中1至3只成分交集而出现候选，新规则下不再显示这些低权重弱匹配。切换到债股联动后返回，成分股和ETF结果保持当前板块身份。
- 可转债行情本次读到317只，通过发行条款正股代码精确关联314只，另3只无可靠映射而排除。来源是东方财富公开延时行情，不是交易所实时推送。涨跌差按债券涨跌幅减正股涨跌幅，单位百分点，不表示统计相关性；缺少现行转股价时不推算溢价率。

## 边界

ETF候选仍依赖少量季度披露前十大持仓与人工主题名称映射，不能当作完整持仓分析或跟踪指数认定。可转债与正股数据为公开延时快照，页面展示的是数据源覆盖范围内的联接，不构成投资建议或交易信号。
