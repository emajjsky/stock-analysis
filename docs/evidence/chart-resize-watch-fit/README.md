# 图表伸缩与自选列适配验收

2026-11-05，正式服务 http://127.0.0.1:8765 ，系统Edge无头浏览器。

## 问题与实现

修复前实测：首页分时右端原为15:00，收起再展开导航后变为14:34。两个共享图表组件启用尺寸变化保留范围，并在resize后恢复原逻辑范围，避免fixLeftEdge重新移动视野。隐藏画布不应用零宽高；用户主动缩放及历史查看不被重置。

自选默认十列所需宽度由1168降至890px。保留16px数字、15px代码、14px表头；减少单元格留白、将单位放在表头第二行，排序箭头不占列宽。详情宽度340–400px，内容区不超过1250px时转为上下布局。保留额外列和必要横滚，不以隐藏溢出来裁掉指标。
