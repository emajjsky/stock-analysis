# 自选行情指标与比较功能验收 · 2026-11-05

本轮按用户确认的同花顺参考补齐自选股的横向比较能力，沿用原配色、较大字体、44px行高、单行工具栏和桌面两侧底部对齐。

默认10列：名称、代码、最新价、涨跌幅、涨跌额、成交额（万元）、成交量（手）、换手率、量比、振幅。列设置另提供买一价、卖一价、今开、最高、最低、昨收、市盈率TTM、流通市值（亿元）、报价时间，共19项。四项基本身份/价格列保留显示，其余可选，支持恢复默认。

点击表头依次降序、升序、恢复原顺序；数值按真实数值排序，双向缺失值始终置后，平值顺序稳定。排序保留当前股票选择，行情更新后自动按当前规则重排。名称/代码及表头固定，表格超宽时内部横向滚动。右侧可收起以完整展示更多指标，并支持分时/买卖五档切换；盘口复用原OrderBook，个股页维持原模式。列偏好与详情显隐保存在本机浏览器。

数据仍使用原Quote接口和缓存更新。成交量后端为SHARES，前端除100显示手；成交额元除10000为万元；流通市值元除1e8为亿元。缺失值显示破折号，真实零单独保留。现手、分钟涨速等未核实字段未加入本轮；没有以估算数字填补。
