## 接口（统一现有 data/meta 信封、会话与同源校验）

### GET /api/v1/data/catalog

`{count:number, source:string|null, updated_at:string|null, status:"EMPTY"|"READY"|"RUNNING"|"ERROR", error:string|null}`。RUNNING 时保留旧 count/updated_at。

### POST /api/v1/data/catalog/sync

空对象请求；排队后立即返回上述状态。重复请求去重。任务在后台执行，不阻塞本地缓存读取。

### GET /api/v1/data/refresh；PATCH /api/v1/data/refresh

返回 `{enabled:boolean, interval_seconds:number, running:boolean, phase:string, last_attempt_at:string|null, last_success_at:string|null, error:string|null, market_open:boolean}`。
PATCH 只接受 enabled、interval_seconds（整数 30–3600）。默认 enabled=true、interval_seconds=60。交易日历未完整接入时 market_open 仅表示工作日时段判断，不作为交易许可。

### POST /api/v1/market/refresh

空对象；排队首页指数/自选/最近访问行情刷新，立即返回上述 refresh 状态。

### GET /api/v1/securities

保留无 q 的旧接口：只返回已物化证券，避免把全目录转成数千次历史查询。
q 支持代码、名称、全拼、首字母，本地查询结果最多 50 条，精确匹配优先；目录与已有证券按真实身份去重，DEMO 不替代真实结果。
新增 `catalog=true&limit=100&offset=0` 返回目录分页（limit 1–100），仍是 `Security[]`；目录记录 quote=null。

### POST /api/v1/securities/{key}/activate

空对象；key 为搜索结果 id（LIVE.SH.600519 等）。物化目录记录，登记最近访问，排队加载报价和最近完成日线，返回 Security；同步忙/失败仍保留本地资料。缓存优先，不等待上游。GET 详情、bars、profile 可读取已激活资料。

### GET /api/v1/market/overview

`{indices:IndexQuote[], breadth:{advancing:number|null,declining:number|null,unchanged:number|null,as_of:string|null}|null, rankings:{gainers:Security[],losers:Security[],amount:Security[]}, updated_at:string|null, status:string, error:string|null}`。

IndexQuote = `{id:string,symbol:string,name:string,price:string|null,change_pct:string|null,volume:number|null,amount:string|null,source:string,source_time:string|null,fetched_at:string|null}`。
八项 symbol 固定为 sh000001、sz399001、sz399006、sh000300、sh000016、sh000905、sh000852、sh000688，顺序对应上证、深证、创业板、沪深300、上证50、中证500、中证1000、科创50。无报价允许 null；禁止演示兜底。排行榜可以暂为空，仅显示缺失状态。

### GET /api/v1/market/indices/{symbol}/bars?timeframe=1d|1w|1mo

返回现有 Bars 结构：`{security_id,timeframe,bars,indicators,limitations}`，成交量统一股；指数供应商单位无法确认时保留缺失并登记。缓存优先，读取时可登记后台加载需求。不存在的 symbol 返回 422。

当日动态 K 线（2026-11-03，REQ-26 修正）：指数与真实个股 `/market/bars` 均在完成历史之上叠加当日报价 OHLC/累计量额，再聚合周/月线并计算显示指标。仅接受上海日期为今天、工作日09:30后、有明确源时区且不超前60秒的有效正价OHLC；0成交量、字段矛盾、无源时间、昨日/未来报价不构造今日棒。未知量额保留null。已有当日完成历史时优先采用历史；叠加不写回历史表、策略或模拟账本。

Bars 新增 `current_bar:null|{time,trade_date,source_time,fetched_at,stale}`。time为当前日/周/月图上动态棒的时间键，trade_date为当日源日期；source_time是上游报价时间，距读取超过120秒标stale。图例显示“当日动态”、源时间、最新价，过期显示“缓存”；光标回看历史时显示对应历史棒。沿用后台配置间隔（当前60秒）与页面10秒缓存轮询，不声称逐笔实时推送。普通GET遵循自动更新开关与失败退避。

历史日线首次按每页2,000根向前分页，至来源起点或保护上限8页；日期参数必须采用YYYY-MM-DD。迁移较短的既有缓存时补拉并追加，不清除原缓存，分页失败/不向前推进时保留旧库并报错。完成后持久化history_complete，后续每日只合并最近日线。指数日/周/月线共用完整来源日线。图表支持半年/一年/三年/全部视窗、可选MA5/10/20/30/60/120/250及MACD、KDJ、RSI副图；轮询只更新数据，不重建图表或重置用户视窗。分时展示昨收基线、光标价格/涨跌幅及独立成交量区。

分时视窗边界（2026-11-03，REQ-26 修正）：滚轮缩放保留右端时间，缩小至全部已有数据铺满后不得继续缩出开盘前空白。全览时随盘中新增点重新铺满，已放大时保留逻辑跨度；原本查看最新数据时继续跟随最新点，回看历史时保留回看位置。换交易日重新适配当天数据。浏览器回归使用独立页面响应夹具，不写入正式行情库。

### GET /api/v1/market/indices/{symbol}/intraday

`{symbol:string,points:{time:string,value:string,volume:number|null}[],source:string,source_time:string|null,error:string|null}`。
time 使用 Unix 秒的十进制字符串或 ISO8601 时间（前端统一转换）；缓存按交易日期隔离。未取到数据时 points=[]，展示无数据状态。禁止拼接跨日曲线。

### GET /api/v1/market/intraday?security_id=LIVE.SH.600519

真实沪深个股分时，返回同上 Intraday 结构。只读缓存并登记有节流的后台需求；激活证券后自动取数，GET轮询不绕过刷新间隔。仅最近访问的有界股票池获取分时。原始成交量为累计值，按已核验规则转换股数后差分；科创股票原单位股，其余当前支持沪深股票为手，指数为手。未确认单位时保留 null，不构造零量。源包含盘后点时保留实际时间。
