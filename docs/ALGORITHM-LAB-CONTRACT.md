## 插件规范

注册定义必须有id、name、version、description、supports、minimum、parameters和schema；支持daily/intraday/news能力逐项声明。新增算法先注册并实现纯函数compute，再加固定输入测试，无需新增页面或模型专属页面。

输入：稳定证券ID、来源和复权口径、按时间升序的完成数据、参数；分时为真实成交价点，不能冒充完整分钟OHLC。当前日线使用最近600根作为指标预热，最长窗口250，16点前排除当日。输出：READY/MISSING、matched、stance、value、reason、markers和算法版本；运行快照记录输入hash、参数和生成时间。

原9项：动量、均线趋势、放量突破、MACD、RSI、布林、ATR风险过滤、盘中涨跌阈值、关联公告。放量突破参考窗口不含当天；前7项支持日线，MACD/RSI另支持分时成交价；涨跌阈值仅分时；公告只作事件提醒。参数有限数值、整数窗口、上下界和能力兼容均由服务端验证。

新增11项：均线金叉、回撤上限、区间位置、缩量整理、价格新高突破、KDJ金叉、收益波动过滤、换手率区间、日内位置、分时均价线之上、分时窗口突破。合计20项。均价线依赖来源真实average_price，不用简单价格平均冒充VWAP；分时突破基于采样成交价，不是完整分钟K线。

分时运行可在计算前刷新输入；全市场只支持3项报价规则，序列规则最多20只。任一所选算法输入缺失或真实来源过期，不计入有效候选，原始规则证据仍保留。报价/序列/公告缓存按批次冻结，逐只来源时点公开，不保证全市场同秒。日线按逐只最近600根查询。盘中午间和收盘分别参照11:30和15:00，旧交易日分时标过期。公告只是近7日缓存目录标题线索，未读正文，未覆盖不等于没有事件。

命中数量、规则得分、模型置信程度均不能作为股票盈利概率。当前不根据个人成本/底仓/可用资金生成补仓、做T或买卖委托。未复权日线存在除权干扰，日K显示可选择复权，但算法原价口径单独注明。长期方向需要接入按时点可用的财务/估值/行业因素，未来的概率必须有样本外验证。

## 自动监测与模型

过期分时报价仍可研究但不触发新通知；实时监测要求来源时间在5分钟内。数据缺失、网络失败保留原缓存和错误状态。关闭行情自动更新时不会绕过开关拉取实时数据。条件编辑/恢复重建基线；事件ID由任务/证券/输入hash组成，重启不重复同一事件。自动检查不挤占手动运行记录。

Jev官方资料：https://docs.typesafe.ai/ ，集成指南https://raw.githubusercontent.com/typesafe-ai/skills/main/skills/typesafe-ai/SKILL.md。官方入口https://api.typesafe.ai/v1/systemone；环境变量TYPESAFE_API_KEY（兼容JEV_API_KEY），可选JEV_MODEL（默认官方别名jev-latest，实际响应版本随运行记录保存）。发送结构化state和两个Noul原子判断（解释是否支持研究提示、解释是否方向冲突），校验answers.<id>.type=noul和0–1 noul值。规则条件已满足、支持判断>=0.8且冲突判断<=0.2才触发后续Agent；中间区域保留提醒交人工观察。失败/未配置/输入缺失均关闭分流，不当作批准。判断概率不等于股票盈利概率。阈值为本产品工作流默认值，未验证投资有效性。微信资料链接返回环境验证页，未声称已读其正文；这里依据TypeSafe Jev官方文档实现。

Agent为后续解释，通过AGENT_API_BASE、AGENT_MODEL、可选AGENT_API_KEY连接OpenAI兼容接口。默认不自动请求。开启后只在新触发时调用，若启用Jev则先通过Jev分流。每任务每小时最多4组自动分析（每组可含Jev与Agent各一次），调用前持久占用预算，失败不自动重复。人工点击复核属于单独请求，可能计费；无模型明确显示待配置。模型不持有下单工具。

## 历史库与客户端

范围为当前目录中的沪深在市证券、来源能提供的未复权完成日线，不含北交所/全退市样本/完整分钟和逐笔历史。最近完成日期从来源上证指数实际日线核对，不用工作日猜节假日。BaoStock 0.9.4每进程独立会话，默认4并行，发行采集最多8；停牌占位行剔除，OHLC无效行保留诊断。已有腾讯整段历史可继续保留，history_coverage.provider_id选定每股研究来源，禁止将两个源的K线逐日拼接。证券目录与用户自选独立。

BaoStock请求固定adjustflag=3；当前服务可能省略复权标识回显，空回显记录为SOURCE_ADJUSTMENT_ACK_OMITTED，明确返回1/2等其他口径仍拒绝。2026-11-15用贵州茅台同一历史交易日分别请求3/2/1，验证三种价格不同，确认参数实际生效；没有把空字段伪造为已回显3。诊断与无效OHLC行剔除分别记录，后者才计入界面“质量提醒”证券数量。

启动首轮拷贝只含公开证券目录与行情的seed到用户data目录，仅当用户库不存在时复制；每次进入前逐股检查target和覆盖状态，增量从该股最后来源日期开始，首次拉取从1990-01-01（实际最早由来源决定）。失败可重试，已成功数据保留；来源修订与旧OHLCV冲突时保留旧值并报错。每25股记录检查点。运行中16点后每日检查一次，服从行情自动更新开关；失败可在发现页补齐历史。

默认用户库：Electron userData/data/workstation.db；WANGZHA_DATA_DIR可重定向。发行客户端默认8766，开发8765，端口占用明确报错，绝不自动连接开发正式库。可设置WANGZHA_PORT，仍仅绑定127.0.0.1。包内seed不得包含自选、账户、策略、模型密钥、研究或用户身份。

## API

- GET /api/v1/lab/catalog、/model-status、/runs、/runs/{id}、/tasks。
- POST /api/v1/lab/run、/tasks、/review、/decision；DELETE /tasks/{id}。
- GET /api/v1/history/status；POST /history/start、/history/stop。
- PATCH /api/v1/lab/runs/{id}：仅修改1–60字批次名称，不改原结果。
- 写入沿用本机会话cookie与Origin校验；模型返回不授予交易权限。

发行验收必须记录真实覆盖数、最早/最近日期、未完成股数、剔除/质量警告、安装包SHA256、测试和Electron实际启动证据；公开源码不包含巨型用户数据库。源码与数据分发许可分别核对。
