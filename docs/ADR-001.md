# ADR-001：分离A股分析核心，先交付同源本地工作台

状态：2026-10-27本轮实施决策；用户授权文档补齐、前后端派生开发及合并。

## 证据

已浅克隆go-stock至.research/go-stock，固定commit 59cfc64917476d21aeaeea921dad0ec0b0d01e62。以实际LICENSE核实GPLv3，消除先前README主分支/缓存导致的Apache与GPL矛盾。Go模块要求go1.27.2，本机go1.27.1；前端为Vue3/Vite/Naive UI，桌面Wails2。

app_signal_monitor.go将信号计算留给前端，定时器用Wails事件唤醒；frontend/src/components/kline/signalMonitor.ts依赖Wails/localStorage并有运行权限门槛；保存信号后存在DispatchOKXSignalTrades调用。其已有交易是OKX逻辑，不能直接当A股可卖批次/T+1/不做T对照。

## 决策及复用边界

保留上游克隆作为只读功能对照，不整仓复制或把其OKX订单接入本产品。本轮保留Vue生态，复用成熟lightweight-charts图表库；新建最小FastAPI业务服务和统一SQLite记录，使前后端通过冻结HTTP契约独立开发。明确这是一条有证据的独立核心路线，未宣称已复用上游生产行情、Agent或执行代码。

不从零复刻同花顺：只开发RPD核心推荐/监测/复核和必要研究界面，行情绘制复用组件。单用户先浏览器同源本地运行；Wails/Tauri打包均不在这次没有桌面验证的情况下宣称完成。

代价：没有直接获得go-stock全部数据适配和功能，须按权限逐步接入；收益：信号不依赖某个图表窗口、Agent无下单凭据、A股模拟账本与OKX隔离、前后端可以契约联调。后续可把本服务作为现有终端伴随服务，但需单独处理许可/桥接。

## 本轮外部依赖限制

用户未提供行情/LLM/券商凭据。默认空库与CSV导入，演示由用户显式启用并标记；LLM未配置返回WAIT，实盘保持禁用。不能以合成数据证明策略盈利或实盘能力。
