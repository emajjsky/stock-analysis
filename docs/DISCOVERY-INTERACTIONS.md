# 发现页操作与状态规范 · 0.3.1

2026-11-15。针对用户录屏中的“运行中离开后丢状态、结果不回显、历史查看与当前配置脱节”修订。以下交互已经实现；证据见 `docs/evidence/lab-workspaces-20261115/`。

## 用户要完成的事

| 阶段 | 用户操作 | 页面反馈与下一步 |
|---|---|---|
| 找候选 | 选股票范围、数据周期、算法与参数；点击“开始选股” | 立即返回任务，显示真实完成只数/总数、已满足与不足只数、当前证券、耗时；允许切页面 |
| 看结果 | 默认查看符合条件的候选 | 可切换全部/数据不足，逐项展开满足和未满足原因；零命中明确解释，可调整条件或看全部依据 |
| 核对个股 | 从候选点股票或“查看K线”；也可在个股分析中独立选股计算 | 日线结果带原算法与依据进入K线；返回发现保留原列表与展开状态；个股计算保存在独立工作区 |
| 持续跟踪 | 从一条结果“加入算法监测”，确认股票、原算法、频率，再启用 | 首次只建基线，之后新触发进入通知与流水；任务可编辑、启停、删除；试算结果直接显示在监测工作区 |
| 重看以前 | 在运行记录点击“查看结果” | 恢复结果所属场景、股票范围、周期、算法参数和组合，收拢配置并定位结果区；明确显示原计算时点 |

日线常用组合提供“趋势＋风险过滤”“低位回升观察”“放量突破观察”入口。用户仍可自由组合；“同时满足”旁说明增加条件会收紧结果，避免把勾选更多算法理解为自动提高胜率。

## 状态归属

| 对象 | 保存位置 | 切页面或刷新 | 关闭整个客户端 |
|---|---|---|---|
| 选股、个股、监测草稿 | 三份独立工作区；小配置存浏览器本地存储 | 各自恢复周期、算法、参数、股票、展开与结果筛选，不共享同一份ref | 下次保留草稿；本地存储不可用时仍可从运行记录恢复完整计算条件 |
| 用户计算任务 | 后端独立线程＋SQLite进度 | 同一任务持续运行，顶栏显示全局入口；重连只查状态，不自动重提 | 尚未完成的任务下次标记“中断”，允许手动重跑，不假装继续或自动重复执行 |
| 完整计算结果 | SQLite `lab_run`，轻量摘要 `lab_run_summary` | 只在完整成功后发布；所属工作区恢复结果ID，完整结果按需读取 | 最近15份完整结果保留；被保留上限淘汰的ID回退到该场景仍可用结果 |
| 监测任务与触发 | SQLite原监测任务/流水 | 页面离开后继续检查，试算与监测任务分开 | 客户端退出后停止，下次恢复任务调度 |

浏览器本地存储只保存小配置与结果ID，不保存几千只股票完整结果。原0.3.0历史记录兼容读取。K线页在应用会话内按证券保留研究上下文；不同证券的算法配置、结果与计算状态独立。

## 计算状态与反馈

`QUEUED → RUNNING → SUCCEEDED / FAILED / CANCELLED`；取消请求期间为 `CANCELLING`。进度只描述已完成的证券，不宣称剩余时间。每25只或约1秒持久检查点；界面约800毫秒查询正在运行的任务，空闲约5秒查询。

一次最多一个用户计算；第二次点击被禁用，后端请求ID也保证幂等。当前正在计算的条件冻结，其他工作区可以继续编辑。再次计算时保留上一份完整结果，标注“新计算进行中”。修改条件后仍展示旧结果，但明确标注“条件已修改”，不把旧结果冒充新配置结果。

取消只停止未完成计算，不写半份成功结果；失败显示具体原因，保留旧结果。进度连接断开时保留已知任务和结果，恢复后重取。服务启动发现未完成任务会核对结果：若完整结果已经落盘，恢复为成功；否则标记中断。

结果区从未运行、计算中、成功有候选、成功零候选、数据不足、失败、取消分别展示。零候选不再显示首次使用占位图。默认“符合条件”，并保留“全部”和“数据不足”的检查入口，所有结果可继续分页展示。

## 接口

- `POST /api/v1/lab/jobs`：提交配置、workspace与request_id，立即返回任务；验证空股票池、个股数量与算法配置。
- `GET /api/v1/lab/jobs`：最近20条任务摘要与正在运行的进度，不包含完整股票结果。
- `POST /api/v1/lab/jobs/{id}/cancel`：请求取消；已结束任务保持原状态。
- `GET /api/v1/lab/runs`：最近15份完整结果摘要；兼容旧记录并首次补建轻量摘要，后续轮询不解析完整全市场结果。
- `GET /api/v1/lab/runs/{id}`：完整结果及原始条件；旧同步 `/lab/run` 保留给单股快速计算与兼容调用。

本次不改变基础算法公式和盈利有效性边界，不增加模拟交易执行。软件反馈的“满足条件”和模型陈述判断概率均不等于股票盈利概率。
