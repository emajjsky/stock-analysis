# 本地分析后端

从项目根目录启动：

```powershell
python -m pip install -r backend/requirements.txt
python -m uvicorn backend.app:app --host 127.0.0.1 --port 8765
```

前端构建到 `frontend/dist` 后，访问 `http://127.0.0.1:8765` 使用同源版本。开发前端通过 Vite 代理访问 `/api/v1`。默认 SQLite 数据位于项目 `.local/workstation.db`；可用 `WORKSTATION_DB` 指定位置。不要将数据库、API 密钥写入版本库。

所有写请求先调用 `GET /api/v1/session` 获取 HttpOnly、SameSite=Strict 会话，再附带本机 Origin 和会话 cookie。仅允许 loopback Host，以及本机 5173/8765 Origin；会话有效期 12 小时。

运行核对（2026-10-28）：当前源码OpenAPI为38路径；正式8765旧进程仍只有35路径，缺少行情同步、同步记录及研究资料同步API。前端静态资源已经读取最新构建，后端尚待重启。本轮自动审批以`blocked by policy`拒绝停止/重启命令，未绕过限制；详见`docs/evidence/real-data-increment/formal-service-check.json`。

## 当前能力与限制

- 空库不会生成账户、报价或推荐。用户明确点击后载入六只虚构企业、固定日期的合成演示；DEMO 代码身份独立于真实导入证券。
- UTF-8/GBK CSV 可预览、逐行检查、事务提交；坏行默认禁止提交，需明确选择部分提交。相同历史行情不会覆盖；数值冲突返回 409。缺失成交额时按收盘×成交量估算，并在来源中标注。成交量单位股，价格复权未知。价格与成交额最多六位小数并原精度保留，超界、过精度、非有限值逐行报错，不静默舍入。
- 日/周/月图、MA、RSI、MACD、ATR、两套选股排序和已完成行情信号。选股默认 `rank-momentum-v1` 按20日收盘动量排序；`trend-stability-v1` 按“20日动量百分数÷14日Wilder ATR占收盘价百分数−最近21根收盘最大回撤百分数”排序。ATR零值排除，21根不足或20日均量为零不参评；成交量仅用于可用性检查和说明。两者分数均为当前股票池名次，不是胜率或财务质量。推荐保存算法版本、输入快照哈希和数据时点。本轮推荐列表保存最近一次选股运行，不混合不同算法分数。算法均为未验证研究基线。信号可手动运行，也可在自选页显式启用持久化自动监测；后者只读取本地保存日线，在服务运行期间按30–3600秒检查，不补跑停机周期。设置页可手动同步腾讯公开报价和最多320根未复权历史日线；外部证券使用`LIVE.*`独立身份，不混入DEMO或CSV。
- Agent 默认返回 UNAVAILABLE/WAIT；显式规则演示标 RULE_DEMO、非 AI。可通过环境变量 `AGENT_API_BASE`（OpenAI 兼容 `/v1` 基址）、`AGENT_MODEL`、可选 `AGENT_API_KEY` 配置真实模型。模型超时或输出格式无效保持 WAIT；过期信号不能批准执行。模型不接触任何交易凭据。
- 模拟初始资金由用户设置。DEMO 账户从演示行情倒数第六个交易日起步，留五次已有日期推进空间；估值、下单均按账户日期，绝不读未来价格。真实导入行情因复权不明，允许创建研究账户但禁止成交。
- 模拟当前仅支持有限沪深主板规则、T+1、幂等、市价式保存收盘即时撮合。手续费是明确示例包，非券商合同：佣金万三、最低 5 元，双侧过户费十万分一，卖出印花税万五。未实现盘口排队、部分成交、撤单、涨跌停完整规则、节假日历、公司行为和实盘。
- BASE 在两侧账本同步；T 仅进入实际账本。累计 T 增益为实际权益减不做 T 对照权益，当日增益另按双方日初权益计算；费用只计一次。后续 BASE 在对照侧约束不足则标 DIVERGED_CONSTRAINTS，不补假资金。开放 T 腿标未闭合并按市值比较。
- 无成熟评价样本时返回 PENDING、空指标，不编造胜率、收益或 Agent 增益。没有任何实盘下单接口。
- 自动监测运行、调度配置、租约心跳及自动复核尝试持久化，支持同进程互斥、过期租约回收和取消检查；服务停止后暂停。运行接口 `GET/PATCH /api/v1/automation`、`POST /api/v1/automation/run`、`GET /api/v1/automation/runs`。自动Agent复核单独开启；只有有效FILTER行动信号和已配置模型才请求，每轮最多5条、同一信号快照最多自动尝试一次，失败不重试，未配置则不调用。调度与模型均无交易权限。该调度器运行在单个FastAPI进程内；多worker副本、独立worker、高可用、跨进程部署与崩溃真实演练仍未验证。
- 真实行情接口为手动触发，运行接口 `GET/POST /api/v1/data/providers`、`POST /api/v1/data/providers/tencent/sync`、`GET /api/v1/data/sync-runs`。只允许固定腾讯HTTPS端点和沪深A股代码；超时、异常、身份或字段错误明确失败，不使用DEMO兜底。快照保存源时间、抓取时间和原始响应哈希；历史日线独立表保存，成交额缺失为未知，不用收盘×成交量猜测。该接口不是持续实时订阅，不含商业授权、SLA或交易所级行情保证。

## 验证

```powershell
python -m pytest backend/tests tests -q
```

测试覆盖空库、会话与来源、导入坏行及冲突、真正落盘恢复、指标预热、信号去重、Agent 未配置、T+1、幂等冲突、报价日期切片、DEMO 推进上限、先买后卖库存容量、连续做 T 和当日/累计对照。

本轮全量后端及集成测试105项通过；包含研究资料解析/入库边界、真实数据入库边界和腾讯解析边界。前端23项通过，`npm run build`类型检查及生产构建通过。真实Edge浏览器数据链路验收通过：同步2只真实证券、保存640条未复权日线、同步公司概况/4期财务摘要/10条公告标题、渲染日/周/月K、真实证券池选股、自选和信号流程；证据位于 `docs/evidence/real-data-increment/`。自动监测专项证据仍位于 `docs/evidence/automation-increment/`。

共享 SQLite 连接的全部查询与写入在同步操作内使用同一把可重入锁，完整读取游标后释放，避免多路页面请求交叉使用缓存语句。新增真实 HTTP 并发回归：20 次选股、每次同时刷新10个接口，验证状态码、证券身份与推荐数量。未处理异常记录请求 ID、方法、路径和服务端栈，不记录请求正文、密钥或账户资料。
