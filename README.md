# 王炸 · A股算法研究客户端

个人本地股票研究工作区：行情首页、全市场搜索、自选监测、算法推荐、Agent复核及独立模拟交易。Vue 3 / TypeScript / Vite + FastAPI / SQLite，波普复古界面。

## 本轮交付（2026-11-15 / v0.3.0）

0.3.2升级修复：原有用户目录缓存旧页面，导致新客户端仍没有进度、切页状态丢失。现启动刷新HTTP缓存、核验服务版本，入口禁止缓存，并增加滚动和切页始终可见的筛查进度条；保留用户配置和数据库。本地最新版为`release/Wangzha-0.3.2-win-x64/王炸.exe`。见[升级复验](docs/evidence/client-upgrade-20261115/)。下面0.3.1为历史交付，干净配置验收遗漏的升级缺陷已在0.3.2修复。

0.3.1交互修复：发现页计算独立后台执行，切页/返回/刷新保留进度和结果；选股、个股、监测各自保留配置；历史结果恢复原条件并定位结果区；零命中有解释和全部依据入口。见[操作与状态规范](docs/DISCOVERY-INTERACTIONS.md)及[真实客户端验收](docs/evidence/lab-workspaces-20261115/)。该轮本地发行目录为`release/Wangzha-0.3.1-win-x64/王炸.exe`，沿用独立用户数据目录，保留原0.3.0客户端。

- 发现页统一多算法筛选、个股计算、持续监测、运行记录；接入9项确定性研究规则。参数/数据周期/组合由用户配置，已启用任务在服务运行时自动检查并生成通知。
- 个股算法依据与日K日期标记复用原有图表，显示输入日期、原价口径、数据不足和方向分歧。规则命中和Jev判断概率均不等于股票盈利概率。
- Jev按TypeSafe官方`POST /v1/systemone`的结构化Noul协议适配；判断拆为解释支持与方向冲突，再由代码决定是否调用Agent。需用户自己的`TYPESAFE_API_KEY`，未配置时不发起请求；尚未进行付费服务实测。
- Windows x64便携包包含Electron、冻结Python服务与公开行情发行库；无需单独安装Python/Node。每次启动先检查缺失完成日线，可显式用缓存进入，进入后服从行情更新设置。16点后每日检查一次日线。包内具体覆盖、截止日期、质量剔除与SHA256见`history-manifest.json`。
- 发行库仅含目录/公开行情，不含本机自选、账户、模型、任务或私人研究；首次复制到独立用户目录，之后不覆盖用户库。历史使用逐只整段来源，公开报价/算法/模型/交易权限独立；本轮不新增自动交易。

算法/API/交互规范见[ALGORITHM-LAB-CONTRACT](docs/ALGORITHM-LAB-CONTRACT.md)，构建与使用见[desktop/README](desktop/README.md)，实测证据见`docs/evidence/algorithm-lab-20261115/`。

## 上一轮底座（2026-10-29，历史记录）

- 默认行情首页：八指数、分时、日/周/月 K 线、成交量、自选摘要，涨幅/跌幅/成交额 Top100。
- K 线按每页 2,000 根向前分页补齐来源历史，上证指数可追溯至 1990 年。可切换半年、一年、三年和全部范围，支持 MA5/10/20/30/60/120/250、成交量及 MACD/KDJ/RSI；轮询更新保留缩放位置。
- 已下载并保存 **5,222只沪深证券基础资料**，支持代码、中文、全拼、首字母搜索；回车直接打开个股，自动加载报价、分时和历史日线。
- 启动先读本地缓存，后台检查目录并刷新行情。默认开启数据更新，盘中60秒，休市至少300秒；排行榜至少300秒，失败退避。设置可修改或暂停。
- 目录日更新；报价缓存、单日分时和完成日线分别保存。打开过/自选证券补历史，每轮最多5只；最近访问最多3只获取分时，不下载全市场多年历史。
- 原有CSV导入、指标、两类历史排序基线、自选规则、信号、Agent结构化复核及独立DEMO模拟账本继续保留。
- 正式服务 `http://127.0.0.1:8765/` 已切换新后端，运行时47条路径与导出契约一致。原有业务数据已备份并校验保留。

数据来自新浪公开证券目录/榜单、腾讯公开行情；当前这些接口无需用户填写API Key。公司概况、财务摘要和公告目录由东方财富研究接口单独手动同步。模型凭据在独立模型配置中管理。行情源可能延迟，按来源时间展示；当前采用轮询，尚无交易所授权持续推送。

## 启动

建议Python 3.12和已安装的Node.js/npm，PowerShell中执行：

```powershell
python -m venv .venv
.venv/Scripts/python -m pip install -r backend/requirements-lock.txt
Set-Location frontend
npm ci
npm run build
Set-Location ..
.venv/Scripts/python run.py
```

打开 http://127.0.0.1:8765/ 。前后端同源，只绑定本机。前端更新后重新构建即可；后端代码变更需重启服务。首次无基础库时自动下载，失败显示状态并保留缓存，设置可手动重试。

默认数据库 `.local/workstation.db`，可通过 `WORKSTATION_DB` 指定。不要清空数据库解决版本问题。`WORKSTATION_AUTO_DATA=0` 禁用后台行情网络任务，读取缓存不受影响；设置中的更新开关用于日常暂停。后台数据更新与自选算法自动监测是两个独立开关。

自选算法监测默认关闭；可设30–3600秒并独立启用Agent复核，未配置模型不调用。停机期间不运行。数据刷新不自动选股、请求Agent或下单。

前端开发：在frontend目录执行 `npm run dev`，Vite将API代理至8765。保持地址127.0.0.1或localhost。

## 日常使用

Windows发行版：完整解压便携包后双击 `王炸.exe`，在启动补数窗口检查历史覆盖，再进入发现工作台；内置Python运行时。源码开发仍可双击根目录 `启动王炸.cmd`。普通浏览器版访问8765，跨域新窗口完整管理需使用桌面客户端。

“自选”下已新增“新股”，本机入口 `http://127.0.0.1:8765/#/ipo`。A股发行/审核/转债有原生数据页，港美股目前使用原站浏览；预披露当前为申报目录，具体覆盖与实测见 [新股与网页行情验收](docs/evidence/ipo-web/coverage.md)。

1. 首页查看指数，切换分时/日/周/月；下方切换三类Top100。
2. 搜索 `600519`、`贵州茅台`、`guizhoumaotai` 或 `gzmt`，回车打开个股；多结果时使用上下键和回车或点击。
3. 加入自选；在发现页选择多算法选股、个股计算或持续监测，核对各项依据与数据日期；Agent复核需单独配置并显式启用。
4. 设置页管理基础库、自动刷新、历史导入和模型；单只股票补数保留在高级折叠项。
5. 模拟交易单独进入，初始资金自行填写。真实行情与演示隔离，外部未复权历史不能直接用于当前DEMO撮合；实盘未开放。

## 数据和验证边界

- 当前目录为来源中的沪深在市证券范围，不含北交所和完整退市历史。302开头新创业板证券已支持研究查询，执行品种未扩展。
- 沪深在市证券历史库覆盖以发行清单为准。全退市无幸存者偏差研究池、完整公司行为校正、模型训练与策略收益验证仍属后续工作；现有行业、概念及资金流向页面的具体数据源范围见各功能验收记录。
- 分时按证券/指数的单个源交易日缓存，不是全量逐笔或分钟历史归档。未完成的当日日线不进入历史指标；16点后补齐当日完成日线。
- 工作日交易时段只是刷新调度近似，尚未接完整交易日历，不能作为交易许可。公开接口可访问不代表商业授权或SLA。
- DEMO仅显式载入，不用随机数据填补真实来源失败。模拟账户不写死金额，Agent无下单权限，实盘无发单接口。

CSV支持UTF-8/GBK，最小列 `code,date,open,high,low,close,volume`，可选name/amount及基本中文列名。代码按文本保留前导零，日期YYYY-MM-DD。样例 [examples/history.csv](examples/history.csv)。同花顺私有二进制文件尚未验证。
